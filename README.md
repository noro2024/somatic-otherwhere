# SOMATIC / OTHERWHERE

手の動きから、不定形な3Dビジュアルと音を生成するWebアプリの試作です。

## 使い方

「カメラで読み取り」を押してカメラを許可してください。手の認識後、映像と音が変化します。「停止」でカメラと音を停止します。カメラはHTTPSまたはlocalhostで利用できます。

- MediaPipeによる最大2手・各21点の認識
- Three.jsによる骨格、変容、粒子、3D計器
- 指関節・手の動き・履歴に反応するWeb Audio合成
- JSONでの動作記録・再生（映像・音声は保存しません）

カメラ映像と推論は利用者の端末内で処理します。映像・座標をサーバーへ送信しません。モデル等は初回アクセス時に配信サーバーから取得します。

## ローカル起動

Node.js 24推奨。

```sh
npm ci
npm run assets
npm run dev
```

```sh
npm run build
```

`dist/` を静的HTTPSサーバーへ配置できます。GitHub Pagesにはmainへのpushで自動デプロイします。初回ビルド時にGoogle公式モデルを取得します。

## 注意

試作段階です。認識精度、実寸、遮蔽時の姿勢は保証しません。骨・筋肉は21点を補間した表示用モデルです。音量と発光は画面下で調整できます。長時間・全端末での動作保証はありません。
